# Video Game Sales Analysis

## Project Description

This project analyzes historical video game sales data from the Ice online store to identify the factors that contribute to a game's success. Using data available through 2016, the analysis aims to uncover trends and provide insights that support marketing and advertising decisions for 2017.

## About This Project

This project was completed as part of Module 1 of the TripleTen Data Science Bootcamp.

The project focuses on applying exploratory data analysis, data cleaning, visualization, and statistical analysis techniques to generate actionable business insights from real-world data.

## Dataset

The dataset contains information about:

- Video game sales across different regions
- Gaming platforms
- Genres
- User and critic reviews
- ESRB ratings
- Release years

## Project Objectives

- Identify characteristics of successful video games
- Analyze sales trends across platforms and genres
- Evaluate the influence of reviews and ratings on sales
- Compare regional market preferences
- Generate recommendations for 2017 marketing campaigns

## Methodology

1. Data preprocessing and cleaning
2. Exploratory Data Analysis (EDA)
3. Data visualization
4. Statistical analysis and hypothesis testing
5. Business recommendations

## Key Findings

- **PS4 and Xbox One were the most promising platforms for 2017**, while several previously dominant platforms were already in decline.

- **Action, Sports, and Shooter were the strongest-performing genres**, with Shooter delivering the highest average sales per game.

- **Consumer preferences differ significantly across regions**, making localized marketing strategies essential for maximizing commercial success.
